# trevorkeenan.github.io

Static source for the Keenan Group website, published with GitHub Pages at <https://www.keenangroup.info/>.

## FLUXNET Data Explorer integration

The FLUXNET Data Explorer is maintained and deployed from the standalone [`trevorkeenan/fluxnet-data-explorer`](https://github.com/trevorkeenan/fluxnet-data-explorer) repository. Its preferred public URL is <https://www.keenangroup.info/fluxnet-data-explorer/>.

This website repository retains `fluxnet-explorer.html` as a compatibility page for the former URL, along with navigation and resource links to the current Explorer. Explorer application code, metadata snapshots, refresh workflows, tests, release metadata, and citation metadata belong only in the standalone repository.
